# 利用者向け両面マーカーPDF 0.6.2

更新日：2026-09-21

追記：0.7.0でマーカー画像をハロウィン仕様へ更新した。両面ページ構成と印刷設定はこの文書を継続し、画像素材と認識データの変更は[halloween-markers-0.7.0.md](halloween-markers-0.7.0.md)に記録する。

## 構成

- 全10枚版は20ページ。TUTORIAL、H01〜H08、ANSWERの順に並ぶ。
- TUTORIAL単独版は2ページ。
- 奇数ページはマーカー面、直後の偶数ページは同じカードの案内面。
- 印刷設定はA4縦、倍率100%、両面、長辺とじ。

## 表面

マーカー、カード種別、カードID、読み取りの短い案内だけを表示する。旧PDFにあったセット構成、素材版、ページ番号、印刷管理文、50mm目盛りは表面から除いた。マーカー画像そのものは変更していないため、MindARの認識データとtargetIndexは従来どおりである。

## 裏面

カードID、れんしゅう・ヒント・こたえの役割、子ども向けの使い方を表示する。ヒント本文と正解は書かず、裏面だけを見ても推理内容が分からない構成とした。印刷担当者向けの長辺とじ指定と50mm目盛りは下部へまとめた。

## 確認

- 全10枚版が20ページ、TUTORIAL単独版が2ページであることを自動検査。
- 全ページをPNGへ変換し、TUTORIAL、H01、ANSWERの表裏を原寸相当で目視確認。
- PDFのテキスト抽出で、各奇数ページのIDと次の偶数ページのID・案内が対応することを確認。
- 実際のプリンター固有の両面方向と余白は未確認。最初にTUTORIALの2ページ版をA4・100%・長辺とじで試し刷りする。
