# 両面マーカーPDF

更新日：2026-09-28

追記：0.7.0でマーカー画像をハロウィン仕様へ更新し、0.7.1で偶数ページをスタッフ用の最小情報へ変更した。0.7.3ではマーカーを190mm角へ拡大し、偶数ページへゲームURLとQRを追加した。両面ページ構成と印刷設定は継続する。

## 構成

- 全10枚版は20ページ。TUTORIAL、H01〜H08、ANSWERの順に並ぶ。
- TUTORIAL単独版は2ページ。
- 奇数ページはマーカー面、直後の偶数ページは同じカードのスタッフ用情報。
- 印刷設定はA4縦、倍率100%、両面、長辺とじ。

## 表面

190mm角のマーカー、カード種別、カードID、読み取りの短い案内だけを表示する。印刷管理文と裏面案内は表示しない。マーカー画像そのものは変更していないため、MindARの認識データとtargetIndexは従来どおりである。

## 裏面

スタッフ用にカードID、用途、設置場所、設置・回収確認、ゲームページURLとQRを表示する。ヒント本文と正解は書かない。印刷担当者向けの長辺とじ指定と50mm目盛りは下部へまとめた。

## 確認

- 全10枚版が20ページ、TUTORIAL単独版が2ページであることを自動検査。
- 全ページをPNGへ変換して配置を目視確認。10枚すべての裏面QRを画像から読み取り、公開URLとの一致を確認。
- PDFのテキスト抽出で、各奇数ページのIDと次の偶数ページのID・URLが対応することを確認。
- 実際のプリンター固有の両面方向と余白は未確認。最初にTUTORIALの2ページ版をA4・100%・長辺とじで試し刷りする。
