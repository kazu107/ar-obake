# 0.8.0 利用者向け表示とマーカー角度

利用者の画面、読み上げ用ラベル、おばけのせりふ、カード表面をひらがなへ変更した。スタッフ画面、検証画面、印刷手順、カード裏面はスタッフ向けとして漢字を残している。内部のH01〜H08・TUTORIAL・ANSWER、targetIndex、ゲーム保存キーは変更しない。参加者には「いちばん」〜「はちばん」「れんしゅう」「こたえ」と表示する。

## 色とアイテムの確認

カメラ下部の8要素はボタンになった。押すと、その端末で取得したヒントから求めた状態を画面内の吹き出しで示す。

- 除外：この いろでは ないよ。／この もちものでは ないよ。
- 候補：この いろかも しれないよ。／この もちものかも しれないよ。
- 確定：この いろだよ！／この もちものだよ！

ヒント未取得では全要素が候補になる。保存された正解を先に見せず、既存の候補演算を使う。開いた吹き出しは新しいヒントの自動記録とともに更新する。同じ要素を再度押す、×を押す、外側を押す、Escapeで閉じられる。カメラやARの認識を止める操作ではない。これは画面下のメモの説明用であり、おばけのせりふは従来通りThree.jsのARメッシュで表示する。

## 角度設定

`/?staff=1`の「マーカーごとのおばけの角度」でカードごとに選ぶ。

| 設定 | 設置例 | 表示 |
| --- | --- | --- |
| 平行 | 壁に貼る | 従来と同じ、カード面に沿った向き |
| 垂直 | 机に置く | カード面から立ち上がり、カードの下辺を向く |

初期設定はH01〜H03のみ垂直、その他は平行。端末ごとのローカル保存で、グループのゲームリセットでは消えない。「角度を初期設定に戻す」は角度のみを戻す。変更は次のカメラ開始から反映する。別端末にはその端末で設定する。

垂直は表示用グループをX軸に90度回転し、足元がカードに埋まらない高さへ移動する。カメラへ近づく方向に立ち上がるので、平行の65%のサイズにして縦画面でもせりふが収まりやすくした。おばけとAR吹き出しが同じグループに入る。静止保持の追跡行列には変更を加えない。垂直のカードを真正面から見ると、直立したおばけは横や真上から見る向きになるため、机に置き、カードの下側から斜めに見る。

## 印刷と端末の更新

素材版は`halloween-hiragana-v1`。カード表面の英字・数字・カタカナも変更したため、新版PDFの全10枚を印刷し直す。画像と認識用`.mind`は全セットを一緒に再生成した。190mm角・A4・100%・両面・長辺とじは同じ。スタッフ用裏面のID、URL、QRは維持する。

通信のある状態でページを再読み込みし、スタッフ画面のアプリ版0.8.0を確認する。既存のオフライン準備は新版で再実行する。Wi-Fiを切るタイミングは、従来通りカメラ映像が出た後。ミッション版2と答え「青い帽子」は維持し、既存のゲームのメモは復元できる。

## iPadでの確認

1. 「れんしゅう」の新版カードで開始し、せりふと画面がひらがなであることを確認する。
2. H01〜H03を机に置き、カード下辺から斜めに見て、足元と吹き出しの向きを確認する。
3. H04を平行／垂直に切り替え、カメラを再開して反映を確認する。
4. メモの8要素を押し、候補・除外・確定の吹き出しと閉じる操作を確認する。
5. 次グループへのリセット後も角度が残り、オフライン更新後も使えることを確認する。

PCの合成カメラ試験は、印刷物・iPadの実カメラによる受け入れ確認とは別に扱う。
