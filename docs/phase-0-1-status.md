## PCで確認した内容

- Node.js 24.19.0、Vite 7.3.6で型チェックとproduction build成功。
- 0.1.5時点のVitestは58項目に合格。0.3.0ではゲーム・保存・問題分析を含め91項目に合格。
- 画像ハッシュ、.mind内の全target順序と部分セットの一致、GLB構造・容量、PDF存在を検証。
- Chromiumに合成カメラ映像を渡し、実際のMindARで1枚・4枚・9枚セットの全IDを認識。
- おばけの3D表示を画像で確認。390px・768px・1024pxの画面幅で横方向のはみ出しなし。
- 停止・開始中の取消・JSON書き出し・再読み込み後のログ保持を確認。
- 権限拒否、認識データのHTTP 503、10秒の未検出、バックグラウンド通知の処理を自動確認。
- 再生のAbortErrorを注入し、自動再試行でAR起動を確認。再生のNotAllowedErrorを注入し、直接ボタン操作からAR起動を確認。ボタン待ちの停止も確認。
- 印刷PDFの全9ページをレンダリングして配置を確認し、日本語フォントを埋め込んだ。

認識・表示の自動確認結果は`browser-test-results.json`、障害経路は`browser-error-test-results.json`に記録。合成映像とSwiftShaderによる試験であり、実際の印刷物・カメラ・Air 2での速度を保証するものではない。
