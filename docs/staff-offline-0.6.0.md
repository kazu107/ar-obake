# 色・アイテム更新／スタッフ運用／オフライン 0.6.0

更新日：2026-09-19

## Mission v2

- 色を「緑・ピンク・青・黄色」に変更。
- アイテムを「メガネ・リボン・帽子・手袋」に変更。
- 正解は「青い帽子」で固定。
- 旧Missionの赤を緑、紫をピンク、ネクタイを手袋へ対応させ、8枚のヒント構造を維持した。
- 全256通りを再計算し、最小4枚、6枚の24/28通り、7枚の全8通りで一意に解けることを確認した。
- 選択肢の意味が変わるためMission版を2へ上げた。旧Mission版1の途中保存は明示的なリセット後に開始する。

## スタッフ画面

トップページ下部の「スタッフ画面」または `/?staff=1` から開く。

- アプリ版、Mission版、通信状態、オフライン準備状態を表示。
- 練習の完了、取得ヒント、回答回数、開始時刻、経過時間を表示。
- 「次のグループへリセット」は確認画面を経由し、ゲームの記録だけを初期化する。
- 4枚試作、検証画面の記録、他端末の記録には影響しない。

## オフライン準備

スタッフ画面で通信があるうちに「オフライン準備」を押す。アプリ本体、Mission、MindARの10枚・4枚認識データ、GLBを端末内へ保存し、すべて成功した場合だけ「準備完了」と表示する。

Service Workerのキャッシュ名はアプリ版に対応する。新しい版では以前のゲームキャッシュを削除し、プレイ中に自動再読み込みしない。PWAとしてホーム画面から起動する設定も継続する。

## 自動確認

- TypeScript型検査、production build、Vitest 92項目に合格。
- 全256部分集合の問題バランス検証に合格。
- 4枚版と10枚版のブラウザ通し操作、スタッフ画面表示、確認付きリセットに合格。
- production previewでオフライン準備後に通信を切り、スタッフ画面、トップページ、Mission v2を再読み込みできることを確認。
- production previewの実際のMindAR処理でTUTORIAL、H01〜H08、ANSWER、3D吹き出し、自動記録、青い帽子での正解まで確認。

PCのChromium、合成カメラ、SwiftShaderによる確認は、iPad Air 2のオフラインAR性能を保証しない。0.6.0はiPadでスタッフ画面、オフライン準備、通信を切った再起動を確認する。
