# 0.8.1 おばけ3体・比較イラスト・スタッフ確認表

## 実装した3体

| カード | 表示 | 認識後の動き |
| --- | --- | --- |
| TUTORIAL | 白い体、曲線の笑顔 | 片手を上げて振る |
| H01 | 白いおばけが小さなオレンジのかぼちゃランタンを持つ | ランタンと手をゆっくり上げて戻す |
| H08 | 丸い目と大きな口の驚いた顔 | 両手を上げて戻す |

動きは2秒で終わり、手と小物を元の位置へ戻す。認識が一瞬途切れても途中から続き、動きの最初には戻らない。再生から12秒未満の再認識では新しい動きを開始せず、同じカードを映し続けている間は自動で繰り返さない。カメラを再開した場合は、新しいAR画面で再び動く。

`src/ar/ghost-variations.ts`で手・顔・小物を切り替える。体の位置・向き、表示角度を設定する親グループ、追跡行列は動かさない。ゲームはこれまで通り`motion=still`を使う。検証画面の任意の浮遊アニメーションは独立している。

基本モデルは名前を付けたパーツ入りの`public/models/ghost-gestures-v1.glb`（43,836バイト）1つを共用し、かぼちゃと笑顔の軽い形状を追加する。古いオフラインキャッシュの基本モデルと混ざらないよう、新しいモデル名を使う。新しいモデルとスタッフ資料もオフライン準備に含める。

## 比較イラスト

`output/imagegen/ghost-variants-concept-v1.png`に全10体の案を並べた。画像生成には内蔵`image_gen`を使い、[生成プロンプト](../assets/source/ghost-concept-prompt.txt)を保存した。Web公開用の同一画像は`public/ghost-variants-concept.png`。

これはデザイン比較のイラストであり、実際のARモデルのスクリーンショットではない。今回の実装はTUTORIAL・H01・H08。H02〜H07とANSWERの小物・動きは[バリエーション案](ghost-variation-proposals.md)として残す。

## スタッフ用設置確認表

`output/pdf/ar-obake-staff-placement-checklist.pdf`はA4横・1ページ。印刷して手書きで、会場・日付・担当・端末と、全10枚の設置場所、実際の表示角度、読み取り確認、設置／回収を記入できる。

各行には初期設定を併記し、H01〜H03は垂直、その他は平行。実際に設定した方の空欄へチェックする。ゲームURLとQR、3体の動きが止まる確認も付けた。アプリのスタッフ画面と印刷ページから開ける。確認表自体は端末の設定を変更しない。
