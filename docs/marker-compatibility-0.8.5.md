# 0.8.5 カード表面とカメラ画面の整理

カード表面を以前のH01〜H08・ANSWER・TUTORIAL表記に戻した。カメラ画面の「かめらを やすむ」ボタンを削除した。画面内の色・アイテムのメモ、左上の設定、相談の操作は引き続き使える。タイトルへの移動・相談・リセット時やバックグラウンドへの移動ではカメラを停止する。

## 印刷済みカードの互換性

| 印刷物 | 0.8.5での扱い |
| --- | --- |
| ハロウィンの英数字版（0.7.0〜0.7.3） | そのまま使える。今回の配布画像もこの版へ戻した |
| ハロウィンのひらがな版（0.8.0〜0.8.4） | そのまま使える。全10枚の認識を別に確認済み |
| ハロウィン柄になる前のカード | 図柄が異なるため、今回の互換性の対象外 |

英数字版のPNGと認識データはGitの3497b08から復元した。H01〜H08・ANSWER・TUTORIALの10 ID、targetIndex、画像の800×800サイズを維持した。ひらがな版は中心の文字と下端の表記が異なるが、周囲のハロウィン図柄は共通する。ひらがな版の原本10枚を`tests/fixtures/markers-hiragana-v1/`に保存し、実際のMindARへ合成映像として入力して確認した。端末へ追加の認識データをダウンロードさせる構成にはしていない。

両面PDFは全10枚・20ページと、TUTORIAL単独・2ページを更新した。マーカーは190mm角、裏面はスタッフ用の最小情報とURL・QR。新しく印刷する場合はA4・100%・両面・長辺とじを使う。既存のハロウィンカードを使う場合、再印刷は不要。

## 進捗と更新

Mission版2、メモの保存キー、色・アイテムと答え、マーカーごとの角度設定は維持した。オフラインキャッシュに前回のひらがな版のMission JSONが残っていても、読み込んでカメラへ進める。互換性のない認識素材や誤ったtargetIndexを許可することはない。

iPadは通信できる状態でスタッフ画面を開き、アプリ0.8.5を確認してオフラインデータを更新する。ゲームを開き、映像が出てからWi-Fiを切る順序は同じ。印刷済みのカードでTUTORIAL・H01・ANSWERを確認する。

## 検証記録

- 単体テスト130項目：前回のMission JSONとメモの復元、未知の素材版・誤った認識順の拒否を含む。
- `nine-game-real-ar-results.json`：英数字版の全10枚を実際のMindARで読み、正解まで進める。
- `hiragana-marker-real-ar-results.json`：前回のひらがな版の全10枚を同じ配信用ビルド・認識データで読み、正解まで進める。
- `camera-entry-browser-results.json`、`camera-playback-browser-results.json`：停止ボタンがない画面、設定・リセット・再生拒否からの復帰、前回のMission JSONでの起動。
- `offline-browser-results.json`：準備後に通信を切り、スタッフ画面・ゲーム・必要ファイルを読み込める。
- `marker-pdf-0.8.5-checks.json`：PDFの全22ページを描画。A4、190mmの配置、埋め込んだ原本画像との一致、裏面すべてのQR、原本・公開用・ビルド後のPDFの一致を確認。

PCの合成映像での認識と、印刷物・iPad Safariでの実機受け入れは分けて扱う。
