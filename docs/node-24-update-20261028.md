# Node.js 24系への統一（2026-10-28）

Node.js公式のリリース一覧を確認し、24系の最新である **24.22.1** に開発環境を揃えた。[公式リリース](https://nodejs.org/en/blog/release/v24.22.1)、[公式リリース一覧](https://nodejs.org/dist/index.json)。

| 対象 | 更新後 |
| --- | --- |
| Windowsで通常の`node`を実行 | 24.22.1（`C:\Program Files\nodejs\node.exe`） |
| npm | 11.19.1 |
| `.node-version` | 24.22.1 |
| GitHub Actions | `.node-version`から24.22.1を取得 |
| `package.json`・ロックファイルの必要条件 | `>=24.22.1 <25` |

WindowsのNode.jsは公式MSIを使用するwingetで24.11.0から更新した。Codex同梱版も24.22.1であることを確認した。

`scripts/run.ps1`は通常の`node`を先に確認し、24系かつ`.node-version`以上なら採用する。条件を満たさない場合はCodex同梱版を確認する。必要な版をスクリプト内へ重複して書かず、`.node-version`を参照する。`-Verbose`で選択した版と実行ファイルを表示できる。

この更新では現在の最新24系を固定した。今後の24系更新時は、PCのNode.jsと`.node-version`を更新して再検証する。

## 確認した内容

- 通常の`node --version`が`v24.22.1`、`npm --version`が`11.19.1`。
- 補助スクリプトが通常のNode.js 24.22.1を選択して型チェック・単体テスト130項目に合格。
- 通常のNode.jsをその確認プロセス内のPATHから外した場合も、Codex同梱の24.22.1を選択して型チェックに合格。
- `npm run build`、`npm run check:assets`、`npm run check:mission`に合格。

アプリは0.8.5を維持し、マーカー・認識データ・PDF・ゲームの進捗形式は変更していない。
