# マーカーごとのおばけ案

目的は、見つけたおばけを子どもが覚えやすくし、「どのおばけの話を聞いたか」を相談しやすくすること。0.8.1でTUTORIALの手振り、H01のかぼちゃ、H08の驚きを実装し、0.8.2で残りの7体も実装した。[全10体の実装と検証](ghost-variations-0.8.2.md)を参照。以下の表は採用したデザイン案で、実際のカード表記は「いちばん」などの番号を維持する。

基本は白い体を共通にして、表情、小物、手の動きで個性をつける。推理対象の緑・ピンク・青・黄色や、メガネ・リボン・帽子・手袋を証言役につけると、せりふのヒントと見た目を混同しやすいので、初回は別の小物を使う。色を追加するなら、小物のオレンジ・濃い紫・灰色を少量使う案。

| カード | 利用者向け呼び名の案 | 見た目 | 動きの案 |
| --- | --- | --- | --- |
| TUTORIAL | あいさつおばけ | にこにこ顔、白い体 | 認識時に片手で一度だけ手を振る |
| H01 | かぼちゃおばけ | 小さなかぼちゃのランタンを持つ | ランタンをゆっくり持ち上げる |
| H02 | こうもりおばけ | 肩に小さな濃い紫のこうもり | こうもりの羽だけがゆっくり動く |
| H03 | ねむねむおばけ | 半目、灰色の小さな枕 | 目を閉じてからゆっくり開く |
| H04 | おかしおばけ | オレンジと白の包みのお菓子 | お菓子を差し出して戻す |
| H05 | ほんよみおばけ | 灰色の小さな本を開く | 片手で一度だけページをめくる |
| H06 | おんがくおばけ | 白と濃い紫の小さな鈴 | 手首で軽く振る。音は任意 |
| H07 | ほうきおばけ | 小さなほうき、元気な口 | ほうきをゆっくり左右に動かす |
| H08 | びっくりおばけ | 丸い目、丸い口 | 認識時に両手を上げて戻す |
| ANSWER | たんていおばけ | 灰色のメモ帳を持つ | 回答へ進む前にうなずく |

名前を採用するときも、カード番号「いちばん」などは残す。あいさつ・驚きの動きは認識後に一度だけ、待機はまばたきや小物の動き中心。おばけ全体を常時揺らす動きは、これまでの「プルプル」と混同しやすいため、体の位置・向きは安定させる。再認識ごとに短いアニメーションを連続再生しないよう、再生間隔も設ける。

最初の3体の後に残りへ広げた。小物は低いポリゴン数の形状で作り、体のモデルと基本形状・素材を共用する。鈴の音は付けず、ANSWERのうなずきは顔だけを動かす。平行・垂直の両方で見えることと、実カメラの読み取り・負荷はiPadでも確認する。

正解の「青い帽子」の演出を追加する場合は、正解後の画面に限って表示する。探索中の証言役が答えを直接示す演出にはしない。
