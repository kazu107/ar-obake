# 全画面AR・3D吹き出し・チュートリアル 0.5.0

更新日：2026-09-15

## 変更内容

- 探索と回答マーカー読取中は、ページのヘッダー、タイトル、ヒント本文、記録完了表示をなくし、カメラを画面全体へ表示する。
- 画面上部には終了、状態、相談の操作だけを重ねる。探索中の下部には、色とアイテムの○・×・？だけを小さく表示する。
- セリフはHTML要素ではなく、CanvasTextureを貼ったThree.jsの平面メッシュとして、おばけと同じマーカー姿勢へ追従させる。
- 最初の開始時はTUTORIALカードを読み取る練習を行う。薄緑のおばけと案内の吹き出しが出て、安定認識後に自動で探索へ移る。練習カードはヒント数に含めない。
- H01〜H08とANSWERの画像、targetIndex、保存キーは変更しない。TUTORIALを末尾のtargetIndex 9へ追加し、ゲームでは10枚セットを使う。
- 0.4.0以前の保存にヒントや回答履歴があれば、チュートリアル済みとしてそのまま続きから再開する。

## 全画面表示について

対応ブラウザではカメラ開始時にFullscreen APIを要求する。iPad Air 2のSafariでブラウザのアドレス欄まで消したい場合は、Safariの共有メニューからホーム画面へ追加し、追加したアイコンから起動する。アプリ本体にはstandalone表示用のmeta設定を含めた。Fullscreen APIを使えない環境でも、ページ内ではカメラが全領域を占める。

## 印刷物

- `public/tutorial-marker.pdf`：チュートリアルだけを追加印刷する1ページPDF。
- `public/markers.pdf`：H01〜H08、ANSWER、TUTORIALの順を保った全10ページPDF。
- 既存の9枚は作り直す必要がなく、チュートリアルだけを追加できる。

## 自動確認

- TypeScript型検査とproduction buildに合格。
- Vitest 9ファイル・92項目に合格。
- 問題バランスの全256部分集合検証に合格。
- 10枚の画像ハッシュ、MindAR target順、GLB、PDFを検証。
- 開発用の合成認識で、チュートリアル、全画面カメラ、下部メモ、自動記録、相談、回答、保存移行を確認。
- production previewへ合成カメラ映像を渡し、実際のMindARでTUTORIAL、H01〜H08、ANSWERを認識した。3D吹き出しのDOM代替が残っていないこと、TUTORIALがヒントに加算されないことも確認した。
- PDFを画像へ変換し、先頭のH01、全10枚版のTUTORIAL、単独TUTORIALに欠けや重なりがないことを目視確認した。

PCのChromium、合成カメラ、SwiftShaderによる結果は、iPad Air 2の処理速度や実際の印刷物での見え方を保証しない。

## iPad確認結果

2026-09-16、利用者が0.5.0の案内項目をiPadで確認し、問題なしと報告した。TUTORIAL、全画面カメラ、3D吹き出し、下部メモ、既存ヒントと回答の一連の変更を実機受け入れ済みとする。長時間動作と複数台での会場進行は別の試験として残す。

## iPadで確認する項目

1. Safariを再読み込みし、開始画面で0.5.0と10枚が表示されることを確認する。
2. チュートリアルカードを映し、薄緑のおばけと3D吹き出しが画面内に出ること、自動で探索へ移ることを確認する。
3. H01を映し、ページ見出しやヒント本文がなく、3D吹き出しと下部の小さい色・アイテムメモだけが出ることを確認する。
4. H01を一度だけ自動記録し、同じカードを映し続けても重複しないことを確認する。
5. ANSWERを読み、回答から正解まで進めることを確認する。
6. Safariの枠も隠す場合はホーム画面へ追加して起動し、カメラが全画面になることを確認する。
