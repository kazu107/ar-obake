H02〜H07とANSWERに小物・表情・動きを追加し、TUTORIAL・H01・H08と合わせて全10体を実装した。白い体は共通にし、証言から推理する色・アイテムと混同しない小物を使う。

| カード | 今回の追加 | 認識後の動き |
| --- | --- | --- |
| H02 | 肩の濃い紫のこうもり | 羽をゆっくり動かす |
| H03 | 灰色のまくらと半目 | 目を閉じて開く |
| H04 | オレンジと白の包みのおかし | 手と一緒に差し出して戻す |

| ANSWER | 灰色のメモ帳 | 顔でうなずいてから回答画面へ進む |

## 体を動かさないアニメーション

`src/ar/ghost-variations.ts`で共有GLBの複製に軽い形状を追加する。体の位置・向き・大きさ、追跡行列、マーカーの平行／垂直を設定する親グループは動かさない。動きは認識後に一度、約2秒で終わる。同じカードを映し続ける間は繰り返さず、再認識による新規再生には12秒の間隔を設ける。

ANSWERは安定認識から約1.5秒待ち、うなずきを見せて回答画面を開く。カメラの停止、別画面への移動、バックグラウンドへの移動でこの待ち時間を取り消す。ヒントの自動記録の待ち時間は変更していない。

ページは右から左へ一度だけめくる。動作終了時は固定の開いた本に戻す。手・小物・顔の各パーツは、終了やマーカーを見失ったときに静止へ戻る。共通の箱・球・円柱と素材を使い、追加モデルのダウンロードは不要。

- [実際の3D描画](ghost-variation-browser-results.json)：正面の静止／動作中と、机向けの角度の動作中を確認。全10体を同時に描画した際は最大36,129三角形・130描画呼び出し、GPUエラーなし。この数値はPCの確認画面のもので、iPadの速度測定ではない。
- [ゲーム画面の確認](nine-game-browser-results.json)：ひらがな、メモ、回答待ち時間、端末内の角度保存を確認。
- [MindARの合成映像試験](nine-game-real-ar-results.json)：全10枚の認識と各バリエーション、3D吹き出し、自動記録、ANSWERのうなずきから正解までの流れを確認。H01〜H03は傾けた机の映像で垂直表示を確認。
- [オフライン試験](offline-browser-results.json)：準備後に通信を無効にし、ゲーム・AR素材・スタッフ資料を読み込み。
