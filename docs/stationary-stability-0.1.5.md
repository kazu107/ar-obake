# 固定時の静止保持とSafari表示の確認（0.1.5）

## 受領記録

0.1.4 / stable / still / 960 × 720の同一セッションに、完了した82点と77点の10秒記録がある。利用者はiPadとカードの両方を固定したと回答。平均描画26.46fps。認識通知は約23.75 / 25.45Hzだが、記録点は約8Hzであり、その間の認識更新は復元できない。2回目は最初の保存点が977msで、開始付近の状態は不明。

冒頭2秒を除く隣接記録点間の実測変化：

| 指標 | 1回目 | 2回目 |
| --- | ---: | ---: |
| MindAR入力の平均回転変化 | 0.437度 | 2.022度 |
| 表示の平均回転変化 | 0.102度 | 0.178度 |
| 表示の平均対数奥行き変化 | 0.0128% | 0.0230% |
| 表示中心の平均移動 | 0.216px | 0.479px |
| 表示中心の最大移動 | 2.337px | 2.166px |

pxは45度の仮想画角と720px高から計算した映像座標で、DOM上のピクセルや実際のマーカーとの誤差ではない。奥行き補正は作用している一方、固定中にも姿勢と投影中心の変動が残る。映像未取得のため、輪郭のちらつきなどが加わっている可能性は判定できない。

## 修正

移動中は0.1.4の補正を使う。約650msの観測窓の80%以上が狭い範囲に収まれば、表示行列をそのまま保持する。画面中心・対数奥行きは中央値、回転はQuaternionのmedoidを基準とする。Euler角の境界やQuaternionの符号反転を平均しない。

保持中は、基準からの画面中心0.004、対数奥行き0.035（約3.6%）、回転10度のいずれかを超える変化が180msかつ3更新以上続くと追従へ戻る。大きな移動は40msかつ3更新以上で戻る。瞬間的な外れ値を通さず、基準を入力に合わせて動かさないため、ゆっくりした移動も累積して解除される。認識を失ったら状態を消し、再認識時に新しい位置へ配置する。

保持開始の姿勢に多少の偏りは残る。また、真のごく小さな移動・回転とノイズを完全には区別できず、保持中は小さな動きを抑える。解除後も補間の遅れがある。移動の応答を優先する場合は比較用の「奥行き補正（0.1.4）」を選べる。

画面と10秒記録にheld / followingを追加。保持中の「静止」はマーカー姿勢の保持を示し、明示的に選ぶ「ふわふわ」アニメーションは独立して動く。カメラ処理、マーカー、モデル、描画解像度・アンチエイリアス設定は変更していない。

## 再生検証

`scripts/replay-pose-recording.mjs INPUT_JSON docs/stationary-replay-summary.json`で集計。元の利用者ログや画像はリポジトリ・配信素材へ含めない。

保存入力間を保持して60Hzで描画した比較では、静止保持の開始は1回目1736ms、2回目2474ms。その後は両方とも解除せず、表示行列が一定になる。

| 指標（冒頭2秒を除く） | 1回目：0.1.4再生 → 0.1.5再生 | 2回目：0.1.4再生 → 0.1.5再生 |
| --- | ---: | ---: |
| 平均回転変化 | 0.0657 → 0度 | 0.2165 → 0.0094度 |
| 平均中心移動 | 0.0656 → 0px | 0.4476 → 0.0127px |
| 入力中心との平均距離 | 0.626 → 0.911px | 1.022 → 1.311px |

揺れを減らす代わりに最新入力への一致度は低下する。真の位置を測れていないため、距離指標を位置精度と呼ばない。間引かれた入力の再生なので、実機での再現・改善を保証しない。今回は手持ちだった前回と今回の値を単純比較しない。

単体テストでは静止・外れ値、10/25/60Hz、持続する移動・接近・回転、累積するゆっくりした移動、入力途絶、再認識、不正値を確認。58項目に合格。ブラウザ試験の結果はbrowser-test-results.jsonに記録する。

## 白い紙のようなページ

提供スクリーンショットは、灰色の背景、影付き白紙、アプリタイトルと抽出時刻、大きな本文、操作部品の省略があり、Safariリーダー表示の特徴に近い。利用者はメニューの状態を確認できなかったため、原因確定・修正完了とは扱わない。CSSを原因と決めつけた変更や、ブラウザの表示モードを強制する変更は行わない。

手順ページに、aA → リーダーを非表示、およびWebサイトの設定 → リーダーを自動的に使用するをオフにする方法を追加した。メニューを確認できない場合はiPadOS 15の設定 → Safari → リーダーから対象サイトを確認する。

根拠：[Apple iPadOS 15ユーザガイド](https://support.apple.com/ja-jp/guide/ipad/ipad0669fc3c/15.0/ipados/15.0)。リーダー無効でも再発するなら、通常のSafari画面でのCSS通信・表示を追加調査する。

## 実機で残る確認

960 × 720 / 静止保持 / 静止で、固定中に「静止を検出・姿勢を保持中」と出ている間の見え方を確認する。まだ揺れるなら10秒記録のheld状態と表示行列を照合する。その後、iPadをゆっくり動かして追従の遅れが許容できるか確認する。Safariの白紙表示は自動リーダー設定変更後の再発有無を別に確認する。
