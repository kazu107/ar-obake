# 0.8.3 吹き出しと数字表示

ARのヒント吹き出しを頭の上へ離し、横方向もおばけの中央にそろえる。カメラの縦画面で収まりやすいよう、表示する内容全体を85%にし、平行表示では少し下へ配置する。平行表示のおばけ自体はさらに80%にして上へ寄せ、頭の高さをほぼ保ちながら下端がメモ欄へ重ならないようにする。垂直表示の足元はカード面から同じ高さを保つ。追跡行列とジェスチャーは変更しない。

下部の色・アイテムを押したときの状態吹き出しは5秒で閉じる。別の項目を押すと5秒を数え直す。同じ項目の再タップ、閉じるボタン、画面外のタップ、Escapeでも閉じる。カメラ停止や画面移動ではタイマーを取り消す。新しいヒントで内容が変わっても、押した時点からの5秒は延ばさない。ARのヒント吹き出しはマーカーが見える間表示する。

タイトルは「8にん」、枚数は「10まい」「4まい」、メモの件数は「1 / 8」などの数字を使う。カードの呼び名とせりふは印刷物に合わせて「いちばん」などを維持する。マーカーPNG・認識データ・印刷PDFは変更しない。

## 確認

- 型チェック、128テスト、ビルド、素材の整合性、ミッション分析。
- [ゲーム画面試験](nine-game-browser-results.json)で5秒後の自動終了と、別項目を押した際の数え直しを確認。
- [実際のMindARに合成映像を渡す試験](nine-game-real-ar-results.json)で全10枚の吹き出しとモデルの画面上の余白、自動記録、回答を確認。768×1024の画面で初回表示時の余白を測定し、H01〜H03は机向けの垂直表示。結果の`speechGaps`に各カードの値を保存した。
- [オフライン試験](offline-browser-results.json)で準備後のゲーム・ARコード・素材・スタッフ資料を読み込み。
- 公開サイトの版、ARコード、オフライン準備を照合する。

PCの確認は、iPad実機での見え方・距離・速度の確認とは別に扱う。iPadでは通信できる状態でスタッフ画面を開き、0.8.3を確認してオフラインデータを更新する。Wi-Fiはカメラ映像が出てから切る。カードの再印刷は不要。
